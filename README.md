# smart-city-supervise-platform
智慧城市事项监管平台｜政务后台管理系统

## 📌 项目说明
本项目基于开源模板 **vite-element-template** 进行二次深度定制开发。
基础模板技术栈：`Vue3 + Vite + TypeScript + Element Plus`。
模板仅提供通用后台基础工程骨架：基础布局、自动路由、Axios请求封装、Pinia状态管理、Mock模拟数据等底层基础设施，**不包含任何政务相关业务页面与业务逻辑代码**。

本人基于该脚手架独立完成全部政务业务模块开发，面向智慧城市事项督办、电子监察业务场景，打造一套适配政务大屏的监管后台。针对政务系统视觉需求，自主定制深色蓝紫渐变科技风格UI，实现事项跟踪、时效预警、台账导出、多级目录、精细化权限管控等完整业务能力。

> Node.js 运行环境要求：>= 18.0.0

## 🛠️ 技术栈清单
- 前端框架：Vue3（Composition API）
- 编程语言：TypeScript
- 构建工具：Vite
- UI组件库：Element Plus
- 状态管理：Pinia
- 网络请求：Axios
- 样式方案：SCSS
- 辅助能力：Excel导出、日期时效计算、递归树形渲染、路由守卫、细粒度权限控制

## ✨ 核心业务功能
### 1. 电子监察模块
实现事项全生命周期流程跟踪，自动识别滞留、异常事项并进行标记预警，方便管理人员快速定位待处置任务。

### 2. 时效督办管理
根据事项办理时限自动分类：正常办理、临近超时、已超时；支持多维度条件筛选，精准管控督办进度。

### 3. 数据可视化统计看板
汇总展示事项总量、按期办结率、逾期占比等核心指标，直观反映监管工作运行情况。

### 4. Excel批量台账导出
支持携带筛选条件进行数据导出，自动生成标准化监管台账，满足政务工作归档需求。

### 5. 无限层级树形业务目录
基于递归组件实现多级菜单、业务目录渲染，适配复杂层级业务分类场景。

### 6. 双层权限控制系统
实现**页面访问权限 + 按钮操作权限**双层拦截；根据角色动态渲染菜单与操作按钮。

## 📁 目录结构
src
├── assets # 静态资源、全局样式（自定义深色政务主题）
├── components # 通用公共组件、业务封装组件
├── composable # Vue3 组合式函数（业务逻辑抽离）
├── config # 全局项目配置
├── middleware # 路由守卫、登录鉴权逻辑
├── pages # 所有业务页面（独立开发）
├── store # Pinia 全局状态管理
├── types # TypeScript 全局类型定义
├── utils # 工具函数（Excel 导出、时间处理、通用方法）
├── App.vue # 根组件
└── main.ts # 项目入口文件

mock/ # 开发环境模拟接口（按需精简）
public/ # 静态资源
.env.* # 多环境变量配置
index.html # HTML 入口
package.json # 依赖与脚本命令

🎨 UI 定制改造说明
原模板默认提供浅色通用后台样式，项目进行大规模样式重构：
搭建深色模式 + 蓝紫渐变科技风主题，贴合政务监管大屏视觉规范；
统一全局字体、表格、弹窗、标签、卡片样式规范；
封装预警标签、统计卡片等业务专属视觉组件；
统一全局色调变量管理，方便后期主题快速调整。
⚙️ 针对原始模板优化点
移除项目无用模块：冗余 mock 示例、不需要的自动化部署配置，精简项目体积；
重构全局样式体系，搭建独立深色主题；
新增大量业务工具函数、可复用业务组件；
优化请求拦截器、统一错误提示规则，适配真实后端业务交互；
完善 TypeScript 类型约束，降低维护阶段潜在问题；
新增权限校验逻辑、时效计算逻辑、导出逻辑等业务代码。
